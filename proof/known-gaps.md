# Known Gaps

v0.0.2 contains the first real asset batch and does not install or apply the theme to the live OS.

## Mapping gaps

- None detected.

## Not implemented in v0.0.2

- No live Windows registry changes.
- No Windows shortcut/profile modifications.
- No Windows icon cache refresh.
- No Linux user-theme installation.
- No Linux system-wide theme installation.
- No KDE activation proof.
- No `.desktop` override application.
- No MIME cache update on a live machine.
- No SVG scalable icons; raster PNG fallbacks are used because the accepted art is raster-generated, not true vector.
- No 7TSP/system-resource patching.
