## When To Add A Handoff

Add a dated Markdown file when:

- Work is intentionally incomplete.
- A blocker requires user or environment action.
- A later agent needs exact resume steps.
- A task changes assumptions, risks, or validation status but does not produce a full report.

## Handoff Template

```md
# YYYY-MM-DD - Short Title

## Scope

## Completed

## Remaining Work

## Blockers

## Files To Read First

## Commands Run

## Risks
```
