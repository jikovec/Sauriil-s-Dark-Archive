# v0.0.2 Asset Batch

## Scope

v0.0.2 integrates the first real Sauriil Dark Archive icon batch into the existing v0.0.1 skeleton. It remains an asset/conversion/proof package only. It does not install the Linux theme, modify Windows registry state, change shortcuts, patch system files, or claim full OS-wide icon control.

## Source asset inventory

Inspected source/reference inputs:

- `v0.0.1 Sauriil-Dark-Archive.zip`: extracted as the implementation baseline.
- `003 v0.0.1 skeleton creation.md`: used as handoff and first-batch scope authority.
- `v0 WinRAR SauriilDarkArchive HQ 48x48.zip`: inspected for style continuity only.
- `documentation.zip`: inspected for visual guidelines and cross-platform mapping expectations.

Accepted source art for this release is newly generated raster art under `source/master/raster/`. Existing WinRAR toolbar icons were not mapped directly to OS app/place/MIME icons.

## Rejected/skipped assets

- WinRAR toolbar command icons such as `Add.png`, `Extract.png`, and `Delete.png`: rejected as direct OS icons because command semantics do not match app/place/MIME surfaces.
- Existing WinRAR `RAR.ico`, `SFX.ico`, `Setup.ico`, and related root icons: inspected for style direction, not copied into v0.0.2 outputs.
- SVG scalable outputs: skipped because the accepted v0.0.2 art is raster-generated. Raster art was not wrapped in fake SVG containers.
- Live Windows registry changes, shortcut edits, Linux theme installation, `/usr/share` writes, KDE activation, and MIME cache refresh: intentionally skipped.

## 16/24 simplification notes

The first batch uses simplified, high-contrast silhouettes in the source art itself rather than separate small-size master variants. The 16/24 outputs preserve the main silhouette and one dominant accent color; fine filigree and text detail are intentionally not relied upon at those sizes.

Small-size limitations that remain acceptable for v0.0.2:

- Archive labels (`ZIP`, `RAR`) are identity support at 48+ and not required to read at 16.
- `text-x-python` avoids the official Python logo; the `PY` text is clearer at 48+ than at 16/24.
- Folder variants rely on silhouette plus overlay concept: parchment for documents, cyan arrow for downloads, keep/home shape for home.

## Known gaps

- No live OS application or installation proof.
- No Windows registry modification or shortcut/profile modification.

- No SVG scalable icons for v0.0.2 because no true vector source was created.
- No 7TSP/system-resource patching.
- No drive, shell, device, status, action, symbolic, GNOME-specific, or XFCE-specific icon coverage.
