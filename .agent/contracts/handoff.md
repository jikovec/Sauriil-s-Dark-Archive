# Handoff contract

Lead with the achieved result and actual delivery endpoint. Include only useful
baseline, changed files, decisions, validation evidence, failures, Git/PR links,
release/deployment/live state and unresolved actions. Label intentionally bypassed
gates and external protections when relevant; do not emit ceremonial empty sections.

Link durable reports in reports/ and unfinished continuation notes in handoffs/.
Keep source candidate, commit, remote CI, merged source and live acceptance distinct.
If a step is unavailable, name its exact prerequisite and completed independent
preparation. Identify follow-up separately; do not imply adjacent work is complete.
Sanitize public evidence: no private exports, credentials or machine-specific paths.
