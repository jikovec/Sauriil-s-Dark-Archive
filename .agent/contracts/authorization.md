# Authorization contract

## Adopted source-workflow grant

The owner's 2026-10-07 Repository Agent Toolkit Bootstrap request explicitly
adopts this standing grant for requested work in this user-owned repository.
The grant is adopted with AGENTS.md and replaces its former blanket requirement
for separate explicit Git-operation requests. This policy edit does not authorize
itself: its provenance is the owner's policy-authoring bootstrap request.

For user-owned repositories (`jikovec/*`, `mind-seed-systems/*`, or ownership
otherwise established), ordinary source completion is standing-authorized:
branches/worktrees, edits, commits, fetch/pull, ordinary rebase/merge, push,
PR creation/update, relevant CI/review remediation, ordinary task-related
Issue/Project maintenance, merge after requirements pass and safe completed-task
branch cleanup. Apply this repository's grant here; it cannot amend other repos.
Dropie and VaultGuard instead follow their repository/organization rules.
Unknown ownership requires evidence, not a guessed classification.

## Limits

A local-only, read-only or narrower task limits the grant. Source delivery does
not imply tags, releases, hosted publication, OS install/apply/rollback, archive
regeneration, credentials, migration or private-data disclosure. Those effects
need applicable requested scope. Inspect indirect CI/deployment effects before
push or merge. Preserve the domain gates in [deployment](deployment.md).

Task intent can grant action authority under applicable governance. Scope,
memory, identity labels, credentials and tool access cannot manufacture it.
Revalidate policy/grants at start/resume and before material effects; respect
revocation. Never administratively circumvent externally enforced controls.

No standing authorization exists to reset, stash, discard unrelated work,
rewrite protected history, mutate persistent memory, or change repository settings.
Do not ask again for still-valid scoped authorization. If blocked, prepare the
concrete reviewable result and request only the missing input/authority.
