# Support

## Where work belongs

- Use [GitHub Issues](https://github.com/jikovec/Sauriil-s-Dark-Archive/issues) for concrete repository defects, bounded enhancements, documentation gaps, and tracked project work.
- Use pull requests for proposed repository changes tied to an Issue/work object where practical.
- Use [SECURITY.md](SECURITY.md) for security-reporting rules. Do not place sensitive vulnerability details in a public Issue.

Before filing a new Issue, inspect current Issues and pull requests to avoid duplicate work.

## Scope

The repository documents an icon-theme asset/conversion/proof project with opt-in OS apply/rollback scripts. Historical archives and experimental platform plans do not imply a support guarantee for every Windows/Linux version, desktop environment, application, or live customization path.

Known implementation and verification gaps are tracked in GitHub Issues. Check the live work ledger rather than relying on historical reports for current status.

## Service level

No response-time SLA, commercial support commitment, compatibility guarantee, or guaranteed maintenance period is published.
